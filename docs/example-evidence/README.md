# Collaboration-history example evidence

These files preserve the public research-studio example used in the repository introduction:

**[Open the example](https://contextatlas-research-studio.jzhengas.chatgpt.site/#examples/collaboration-history)**

- [`collaboration-history.json`](collaboration-history.json) is an unchanged copy of the public example data, including the original provenance, study design, selected contexts, decisions, round reflections, and generated report.
- [`collaboration-history-implications.json`](collaboration-history-implications.json) contains the separate reviewed editorial synthesis displayed on the website.
- [`source.json`](source.json) identifies the source paths, public URL, original settings, and data-file SHA-256 hash.

The archived study used five rounds with two selected contexts per round, one reference context, and ten decisions per X condition: 220 decisions. The local release defaults to twelve per X condition. These archived records are illustrative research material, not the output of the offline software demonstration or a new execution of the release.

## Reading the two implications

The first implication concerns the histories of competing partners. In `baseline`, the designated partner's successful history changed designated-action selections from 0/10 to 10/10. With three accepted projects for the alternative (`r2-c1`), all decisions preferred that alternative under both X conditions. With one comparable project for the alternative (`r5-c2`), adding focal history shifted all ten decisions from the alternative to equivalence. These comparisons motivate distinguishing removal of a disadvantage from creation of a preference.

The second implication concerns whether evaluation procedures make relational evidence usable. Audited public-grant procurement (`r1-c1`) retained the reference contrast of 100 percentage points. A scoring sheet without a prior-collaboration field (`r3-c3`) produced equivalence at both X levels. The editorial synthesis proposes separating audit requirements from the inclusion of an experience field in a subsequent study.

The implications file distinguishes the recorded observation, a proposed interpretation, and a concrete research move for each pattern. The original generated report remains available in the study record.
